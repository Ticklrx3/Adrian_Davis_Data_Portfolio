# Adrian Davis Data Analyst Portfolio

This package contains a complete responsive portfolio website built from the project
links and portfolio files supplied by Adrian Davis.

## Files

- `index.html` — website content and project case studies
- `styles.css` — responsive styling
- `script.js` — mobile navigation and small enhancements
- `assets/Adrian_Davis_Resume.pdf` — downloadable résumé

## Preview locally

Double-click `index.html` to open the portfolio in a browser.

## Publish with GitHub Pages

1. Create a new public repository, such as `adrian-davis-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then save.
7. GitHub will provide the public portfolio URL.

## Recommended updates before sharing broadly

- Replace the Tableau Cloud home link with a direct Tableau Public workbook link.
- Add a LinkedIn profile link when available.
- Consider using a professional GitHub account name for recruiter-facing applications.
- Review the included résumé and replace it whenever the master résumé changes.
- Keep all government and employer material sanitized. Do not upload source records,
  personnel data, operational details, or internal screenshots.

## Privacy and security choices

The website does not include the supplied Power Apps export, Excel workbooks, Supabase
backend URL, or government source data. The Power Apps and Excel visuals are recreated
with fictional data, while project scale metrics are based on the supplied file structures.
